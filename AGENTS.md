# Agent instructions

The rules for working in this repository are in [CLAUDE.md](CLAUDE.md). They apply to every coding agent, not only Claude Code. Read that file first.

In short:

- Load the skill that matches the work from `.claude/skills/` (backend, web, mobile, or spec-driven development).
- Follow `specs/` for any non-trivial change.
- Run the checks listed in CLAUDE.md and report only what you actually ran.
- Commits are conventional, with no `Co-Authored-By` line and no AI attribution. Do not commit or push unless asked.
